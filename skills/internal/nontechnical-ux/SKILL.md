# Non-Technical UX

For primary workflows: clear next action; familiar domain language; sensible defaults; hide implementation detail; preserve work; show status/ownership/dates; explain errors/recovery; support correction/undo where reasonable; progressive disclosure; bulk actions for repetition; actionable reporting; verify completion without developer help.
