# Idea lineage

Read existing sources and GBrain records; never rewrite raw sources. Resolve aliases, order by `observed_at`, apply `valid_from`/`valid_until`, and follow explicit `supersedes` links. Report first evidenced appearance (not assumed origin), each view change, evidence or decision causing it, time-qualified conflicts, superseded versions, abandoned/minority branches and the latest supported canonical view. Mark gaps and ambiguous identity explicitly; absence of a record is not evidence that an event did not occur.

Return citations/backlinks for every transition and keep historical branches retrievable.
