# Project Start

1. Clarify the desired user/business outcome.
2. Inspect existing code, history, assets, CI, docs and related repositories.
3. Identify the biggest uncertainty and fastest credible proof.
4. Run competitive/product-pattern and open-source leverage audits where relevant.
5. Reduce broad requirements to P0 MVP / P1 next / P2 later.
6. Select the smallest useful end-to-end slice.
7. Define simple replaceable boundaries.
8. Install/register Major skills without loading irrelevant skill text.
9. Begin the first proof/vertical slice immediately; do not start infrastructure-first or speculative documentation.
