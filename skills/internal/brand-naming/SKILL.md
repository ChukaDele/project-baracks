# Brand naming

Two modes. Pick one first.

- **Mode A: Stress-test an existing name.** Default when the user already has a working name. Cheaper and usually correct.
- **Mode B: Generate a new name.** Only when Mode A produces a hard fail, or no name exists.

Ask which mode applies. If the user has a name and is still generating options, say plainly that this is usually procrastination, then run Mode A.

## Prerequisite

Do not name anything without a positioning and an architecture. If they are missing, use `brand-strategy` first. Naming without positioning produces endless brainstorming.

## The brief (Meyerson)

Write this before any candidate:

- What is being named, and its role in the architecture
- Positioning in one line
- Audience and buying situation
- Naming convention it must fit
- Name type target: descriptive, suggestive, arbitrary, invented, founder, or acronym
- Tone words: three maximum
- Hard constraints: markets, languages, sound-alike risks, domain needs
- Kill criteria: what makes a candidate dead on arrival

## Mode A: Stress-test

Run all six checks. Report pass, weak, or fail for each.

1. **Strategic fit.** Does it support the positioning, or fight it?
2. **SMILE (Watkins).** Suggestive, Meaningful, Imagery, Legs, Emotional. A name needs strength on some of these, not all.
3. **SCRATCH (Watkins).** Spelling-challenged, Copycat, Restrictive, Annoying, Tame, Curse of knowledge, Hard to pronounce. Any hit is a real risk. Restrictive and Copycat are usually fatal.
4. **Linguistic.** Say it out loud. Spell it over a phone call. Check syllable count, stress, sound-alikes, and meaning in target languages.
5. **Search and legal.** Exact-match search, category search, trademark register search, and domain and handle availability. Report findings as risks, not as clearance.
6. **Use in real sentences.** Write five real uses: cold email signature, invoice, voicemail, referral sentence, and a slide title.

Then give one verdict: keep, keep with fixes, or replace. Justify in three lines.

Note on B2B: "Tame" is a soft fail in B2B services. A plain, clear name often outperforms a clever one. Do not force a name to be entertaining.

## Mode B: Generate

1. Write the brief.
2. Generate wide. Work from 10–12 theme words, not from a blank page. Target 100+ raw candidates.
3. Group into spot-on, maybe, and spark.
4. Screen with SMILE and SCRATCH. Cut to 12.
5. Prescreen: search, register, domain, handles, sound-alikes. Cut to 5.
6. Present with context, never as a bare list. Show each name in use, with a short rationale and its risk profile.
7. Send the final 2–3 for legal clearance.
8. Decide by "is it right", not "do I like it".

Never crowd-source the choice by survey. Consensus voting selects the least offensive name.

## Presentation rules

- Show the name in a live sentence the buyer would hear.
- Show a plain wordmark, not a designed logo. Design hides or flatters the name.
- State the risk on every candidate, including the favourite.

## Output format

| Candidate | Strategic fit | SMILE | SCRATCH hits | Linguistic | Search/legal risk | Verdict |
|---|---|---|---|---|---|---|

Plus: the brief, the killed names with reasons, and the clearance next step.

## Limits

- You do not clear trademarks. A qualified attorney does. Say this once, without drama, and record it as an open action.
- Watkins's tests were built for consumer names. Weight them lower for technical B2B.
- A great name does not fix a weak position.
