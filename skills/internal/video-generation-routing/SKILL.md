# Video Generation Routing

Load this skill for explicit AI video generation: cinematic clips, story scenes, product ads, social reels, character-led sequences or storyboard-to-video work. Do not load it merely because a website plays a video or uses code-rendered motion.

## Choose the production path

1. Use **Google Flow** when the work benefits from a scene-building workspace, Google video models, prompt/image inputs and iterative story or shot continuity. Treat Flow as an interactive web product. Check the currently offered model and displayed credit cost in the product before each generation.
2. Use **Higgsfield** when cinematic camera movement, advertising/social formats, character consistency or its multi-model creative workflow is the stronger fit. Treat Higgsfield as an interactive web product unless a first-party API is verified for the current account and task. Check the displayed credit cost before execution.
3. Use **Remotion or another deterministic renderer** for typography, data, product UI, repeatable motion graphics or frame-exact code-controlled output. This is not generative video.
4. Use the smallest route that proves the intended result. A storyboard or one representative shot should precede a costly multi-shot generation.

## Required boundaries

- Load `cost-control` and `human-blocker-orchestration` before a credit-bearing generation or provider login. Show the intended provider, generation scope and visible credit cost. Require the owner's confirmation before spending credits.
- Do not create subscriptions, buy credits or upgrade plans without explicit authority.
- Keep prompts, source media, generated assets and provenance project-local. Do not upload confidential material, credentials, candidate/client PII or restricted project evidence.
- Do not promote provider prompts or generated evidence into global learning. Only sanitized, stable, cross-project procedure may become a global candidate.
- Do not claim a provider, model, API, CLI or account capability is operational until the authenticated runtime proves it.
- Preserve provider watermarks and disclosure requirements. Label synthetic or reference-only output when it could be mistaken for real evidence.
- Save the approved prompt, model/provider choice, input provenance, visible credit cost and output identifier with the project artefact when the provider exposes them.

## Stop conditions

Stop for human action when login, consent, payment, credit use or a rights decision is required. Continue independent storyboarding, prompt drafting and asset preparation while that branch is blocked.
