# Product-pattern research record

| Field | Required content |
| --- | --- |
| Reference ID | Stable local ID |
| Source application/site | Product name |
| Source link | Direct accessible URL |
| Screen or flow | Exact state studied |
| Problem solved | User problem, not visual style |
| Effective | Observable mechanism |
| Ineffective | Risk or limitation |
| Adapt | Principle or structure to reuse |
| Reject | Branding, trade dress or unsuitable behavior |
| Product area | Decision this evidence informs |

Use screenshots only where the source permits it. Otherwise retain the link and a concise visual description. Never promote proprietary screenshots into a reusable asset library.
