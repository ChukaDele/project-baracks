# Open-Source Leverage

Before commodity functionality:
1. Search GitHub and official docs.
2. Inspect licence, releases, maintainers, issues, tests, CI, dependencies and architecture.
3. Estimate adaptation time versus building.
4. Check data/security/source-term risks and exit path.
5. Decide: reuse, adapt/fork, wrap, reference, or reject.
6. Stop researching once evidence clearly favours an option.
