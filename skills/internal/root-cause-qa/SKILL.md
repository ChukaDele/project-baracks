# Root-Cause QA

1. Reproduce.
2. Record actual vs expected.
3. Trace state, inputs and side effects.
4. Find earliest incorrect assumption/transition.
5. Fix cause, not symptom.
6. Check adjacent paths for same pattern.
7. Add regression protection when recurrence is likely/costly.
8. Run critical path.
9. Record reusable lesson and evidence.
