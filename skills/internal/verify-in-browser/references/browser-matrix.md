# Browser verification matrix

Adapt to documented product targets. At 100% browser zoom, sample large desktop, desktop, laptop, short laptop, tablet, large mobile and mobile. Add ultra-wide when the layout uses wide composition.

For geometry-sensitive layouts, stress 67, 75, 80, 90, 100, 110 and 125 percent zoom. Zoom is robustness QA, not a bespoke design mode. Choose responsive behavior from live geometry and capability, not a hard-coded zoom value.

For reduced motion, verify both system preference and any product control. Critical information and actions must remain available without animation.
