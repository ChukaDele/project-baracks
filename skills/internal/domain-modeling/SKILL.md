# domain-modeling

Define a term in one or two sentences, name terms to avoid, test a relationship against a concrete scenario and surface code-to-language contradictions. Record an ADR only for a consequential, surprising, hard-to-reverse trade-off. Do not write a spec, start implementation or impose DDD on trivial CRUD.
