# Source Adapter Engineering

Prefer official APIs/JSON/RSS/sitemaps/structured markup; HTTP parsing before browser automation; one internal adapter contract; preserve source/provenance; canonicalise/dedupe; incremental retrieval/hash/conditional requests; retries/backoff/idempotency/degraded states; track useful outcomes not raw volume; exhaust maintained free/open options before paid infrastructure.
