# Vertical Slice Delivery

- Start from the user/business outcome.
- Reduce scope to the minimum value loop.
- Include UI/interface, domain rule, persistence/integration only as required.
- Use replaceable mocks/fixtures when they accelerate proof.
- Avoid building full horizontal layers in isolation.
- Define clear acceptance evidence.
- Run the critical path.
- Ship/prove the slice, learn, then expand.
