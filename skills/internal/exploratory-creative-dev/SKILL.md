# Exploratory Creative Development

Trigger only when the brief explicitly calls for exploratory/experimental/high-craft creative work.

1. Study 5–10 exceptional relevant references; reverse-engineer composition, typography, pacing, motion, transitions, interaction, illustration/3D and sound where relevant.
2. Define a visual grammar and motion narrative rather than saying 'make it Awwwards'.
3. Prototype the signature/highest-risk interaction before commodity sections.
4. Use specialised parallel roles: creative direction, frontend/layout, GSAP/motion, WebGL/3D when justified, performance and browser/visual QA.
5. Default stack: image/SVG assets, GSAP + ScrollTrigger, Lenis, Motion, GitHub, Vercel, browser/Playwright. Add R3F/Three.js, Rive, Spline or Remotion only when conceptually justified.
6. Avoid generic SaaS hero/card grids, random fade-ups, gratuitous 3D, default AI gradient blobs and animation without narrative purpose.
7. Deploy early, inspect visually, critique and iterate until the intended craft bar is met.
