# Writing OS

For every substantive writing request, use the resolved route; do not wait for the user to name writing skills. Short routine messages use the compressed route. Writing OS owns what to say and how the argument works; Prose Craft owns sentence construction.

1. Before drafting, state internally the audience, purpose, desired action, strongest true useful idea, known evidence, assumptions, genre, risk, and voice profile. Never invent evidence, experience, quotations, citations, statistics, testimonials, cases, or credentials.
2. Invoke the resolved specialist. Research and trace material claims when the genre requires it. Structure around the argument, not a canned outline.
3. Invoke Prose Craft, then voice matching only from an approved corpus. Draft with simple precise language, concrete support, selective rhetoric, and necessary qualifications.
4. Run every gate in the route receipt. Lint and Natural Writing QA detect and explain before targeted edits. The evaluator returns findings only. High-stakes work requires a critic that did not draft the text.
5. Revise only identified defects, repeat affected checks, verify claims/source meaning, and expose a degraded state when a required gate cannot run. Detector scores never override facts or determine quality.
6. Treat accepted edits through the existing learning lifecycle using GLOBAL, GENRE, BRAND, PERSONAL VOICE, PROJECT, or ONE-OFF classification. Do not generalize one-off edits.

Meaning, evidence, legal effect, citations, and technical instructions outrank style cleanup. Academic terminology and qualifications survive naturalness edits. Controlled technical rules apply only on technical routes. Direct-response tactics apply only when a commercial action is required and must reject deception, fake urgency/scarcity/proof, confirm-shaming, hidden terms, and dark patterns.
