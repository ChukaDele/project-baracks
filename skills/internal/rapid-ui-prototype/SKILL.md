# Rapid UI Prototype

Use only when an important interaction has multiple credible options.
- Build 2–3 minimal proofs using the fastest useful medium.
- Test against the real workflow and realistic data/states.
- Compare clarity, speed, error risk, creative quality and implementation cost.
- Use Emil's design/motion skills when relevant.
- Choose one and remove/discard the losers.
