# Cost Control

Prefer subscription-included capacity and the cheapest adequate route; cache stable work; log provider/model/task usage, latency, failure, rate-limit state and real paid cost; use deterministic tools when sufficient; set warnings/caps for actual paid spend; never auto-upgrade/purchase credits/API billing; route around exhausted providers; optimise time-to-verified-outcome, not token minimisation alone.
