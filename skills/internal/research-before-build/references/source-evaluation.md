# External source evaluation

## Primary sources

Use official documentation, the package registry and the source repository. Record the exact page, package version or commit and the date checked.

## Maintenance evidence

Check recent releases or commits, open issues, supported runtimes, test/CI state and whether the relevant feature is stable, beta or experimental. Star counts are context, not proof of fitness.

## License evidence

Record the SPDX identifier and any NOTICE, attribution, source-disclosure, trademark or hosted-service terms that affect adoption. Do not copy material with missing or incompatible licensing.

## Security and cost

Separate open-source license from hosted-service terms. Identify credential handling, network reach, data retention, telemetry and billed units. A free allowance is not permission to create spend.
