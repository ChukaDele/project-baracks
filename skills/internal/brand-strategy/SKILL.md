# Brand strategy

Output four things: a research base, an insight, a positioning, and an architecture.

## Stage 1: Research

Collect evidence before opinion. Use six buckets.

1. **Buyer.** Who signs. Who blocks. What triggers the search. Use category entry points: the situations that make a buyer look for this at all. Write them as "when I need X, at Y moment".
2. **Alternatives.** What the buyer does today. Include doing nothing, a spreadsheet, a junior hire, and an agency. Do not list only direct competitors.
3. **Category.** The words buyers already use. The budget line the money comes from.
4. **Competitive field.** Real screenshots, real copy, real colour, real type. Build a visual and verbal audit grid. This grid is the only valid test of "different".
5. **Company.** What this company can actually do better. Proof, not ambition.
6. **Culture and tension.** What is changing that makes the old answer wrong.

Minimum evidence bar: five buyer conversations or five recorded sales calls. If none exist, mark the positioning as a hypothesis and say so on the page.

## Stage 2: Insight — Pollard's Four Points

Write four sentences. One idea each.

- **Problem.** The business problem in plain words.
- **Insight.** An unspoken human truth that opens the problem up.
- **Advantage.** What this brand can do that others cannot.
- **Strategy.** An informed opinion about how to win.

Reject an insight that is a fact, a statistic, or a restatement of the problem.

## Stage 3: Positioning — Dunford, then Neumeier

Fill the five components in this order. Order matters.

1. Competitive alternatives.
2. Unique attributes — capabilities the alternatives lack.
3. Value and proof — the benefit those attributes create, with evidence.
4. Target market characteristics — the traits that make a buyer care a lot.
5. Market category — the frame that makes the value obvious.
6. Optional: a relevant trend. Use with care.

Then apply the Neumeier onlyness test:

> Our [offering] is the only [category] that [benefit] for [audience] in [region/segment] during [time] because [proof].

If the sentence still reads true when a competitor's name is inserted, the positioning has failed. Go back to step 2.

Then choose the category strategy:

- Enter a known category when the buyer already has a budget line. This is the default.
- Create a new category only when you can fund years of buyer education. Say the cost out loud.

## Stage 4: Architecture

Decide the structure before any naming.

- **Master brand.** One name carries everything. Cheapest. Best for small firms.
- **Endorsed.** Sub-offer with a parent signature.
- **House of brands.** Separate brands. Needs real money.

For each offer, state its role: driver, supporter, or descriptor. Write the naming convention now, so the next offer does not need a new brand.

For a solo or small business, default to a master brand plus plain descriptive service names. Bring a proof to justify anything more complex.

## Output format

One page per section:

1. Evidence summary with sources and gaps
2. Four Points
3. Positioning (five components + onlyness statement)
4. Architecture map with naming convention
5. Killed alternatives and the reason each died
6. Test plan: which claim to test, with whom, and how

## Validation gates

Answer these before you hand over:

1. Which strategic input caused this decision?
2. Which alternatives did we kill, and why?
3. Which buyer or category evidence supports it?
4. Which framework are we using, and where does it stop?
5. Is it different from the real field, evidenced by the audit grid?
6. Can a buyer repeat the position after one hearing?
7. What still needs a real test?

## Limits

- Dunford gives clarity, not distinctiveness. Neumeier gives distinctiveness, not operations.
- Ehrenberg-Bass laws come from large-brand data. For a startup, treat them as direction, not law.
- Do not use archetypes in this stage. Personality comes after positioning.
