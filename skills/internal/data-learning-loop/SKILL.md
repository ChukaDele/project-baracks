# Data Learning Loop

Preserve raw records/provenance; define outcomes and denominators first; account for lag/cohort maturity; use time-based evaluation when needed; separate hard rules from predictive scores; start interpretable; version features/prompts/models/evals; treat correlations as hypotheses; require evaluation before production rule/model changes.
