# Skills

Major-managed skills are installed by profile and tracked in `MAJOR_SKILLS.lock`.

- Core internal skills are available in every Major-managed project.
- UI/Web projects add the complete current Emil bundle plus frontend/browser skills.
- Exploratory projects add creative/generative skills.
- Figma, MCP, security, PDF, deep-graph and skill-authoring skills are specialist triggers.
- Installed does not mean fully loaded into every prompt; use task-relevant skills only.
- External skill instructions are subordinate to `AGENTS.md` and active Major policy.

See the Major repository `docs/skills-catalog.md` for the canonical catalog.
